# Uno Reverse Email Agent

You pitched me. Now it's my turn.

A proposed local-first email agent that turns incoming marketing outreach into an approved pitch for your business, organizes conversations, and tracks responses.

**Status: proposal only.** No application has been implemented, and there is nothing to install or run yet.

## Project proposal

See [the complete proposal](docs/proposal.md) for requirements, architecture, Gmail authorization, review mode, autopilot, and acceptance criteria. The proposed core workflow works without an Optimly account; BrandVault integration is optional.

## Repository decision

On November 5, 2026, the owner selected a standalone private repository at `apurva-2124/uno-reverse-email-agent`. This supersedes the proposal's earlier monorepo location and later repository-creation plan. The proposal is retained as supplied for review; its references to private Optimly architecture are context, not bundled code or dependencies.

Implementation approval and public release remain separate decisions. The product name and proposed Apache-2.0 license still require review; this repository does not yet grant an open-source license.
